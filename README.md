## 🗂️ What This Project Does

An NLP pipeline that automates the extraction and analysis of information from semi-structured interview transcripts:

* **Topic Clustering** — Sentence-Transformers + FAISS vector search
* **Co-occurrence Graph** — identifies concept relationships across transcripts
* **Sentiment Analysis** — Meta Llama-3 via structured RAG prompts
* **Frequency Analysis** — keyword and theme distribution
* **React/Next.js Frontend** — transcript upload, topic visualization, summary export

**Tech Stack:** Flask · FAISS · NLTK · Sentence-Transformers · React · Together AI API
